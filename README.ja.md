# 知影：ローカル AI ナレッジ動画スタジオ

言語：[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

知影（Local Studio）は、PDF、PPTX、Markdown、一般公開ウェブページ、テキストからナレーション付き動画を作成する、Windows ローカル環境向けの制作ツールです。Ollama で資料を整理して絵コンテを作成し、F5-TTS でユーザー提供の音声サンプルをもとにナレーションを生成、Remotion と FFmpeg で横長または縦長の 1080p H.264 MP4 を書き出します。書き出し後は字幕・音声の品質確認、動画ファイルの検証、MP4・字幕・カバー画像・プロジェクトバックアップを含む ZIP の作成ができます。プロジェクトと生成メディアは既定でローカルに保存されます。ウェブページ抽出や Wikimedia Commons の検索・ダウンロードは、ユーザーが操作した場合にのみインターネットへ接続します。

## 主な機能

### 資料の取り込みと絵コンテ作成

- PDF、PPTX、Markdown（`.md` / `.markdown`）、貼り付けたテキスト、ログイン不要の公開ウェブページに対応します。抽出結果を確認・プレビュー・編集してから絵コンテを生成できます。
- Markdown の表は構造化データとして絵コンテ生成に渡します。コード例は内容を説明し、ソースコードをそのまま動画に表示しません。
- PDF のテキスト抽出に対応し、スキャンページにはローカル Tesseract OCR を任意で利用できます。PPTX は抽出内容から再構成する方法と、元スライド画像を保持する方法を選べます。後者には PowerPoint または LibreOffice が必要です。ノートをナレーションの優先情報として使うこともできます。
- ウェブ抽出は公開記事が対象です。ログインが必要な内容にはアクセスせず、localhost やプライベートネットワークへのアクセスをブロックします。失敗時は理由を表示し、テキスト貼り付けに切り替えられます。
- Ollama はローカルで資料を分析し、台本と絵コンテを生成します。長い資料はチェックポイント付きで分割処理し、入力と設定が変わっていなければ失敗箇所から再開できます。

### 絵コンテとビジュアル

- タイトル、テキスト、二階層の箇条書き、表、比較、コード、タイムライン、数式、画像に加え、グラフと図解を統合したビジュアルシーンを作成できます。画面データに応じて数値グラフ、ノード図、二次元表を表示します。シーンの追加・複製・削除・並べ替え、ナレーション・長さ・ビジュアル JSON の編集、シーンごとの音声再生成に対応します。
- 絵コンテをリアルタイムでプレビューできます。Minimal Tech、Clean Light、Academic、Social Short、Whiteboard のスタイルを利用でき、内蔵または自作のシーンテンプレートを挿入したり、現在のシーンを再利用可能なテンプレートとして保存したりできます。
- 絵コンテでシーンを選ぶと、プレビュー動画がそのシーンの開始位置に移動します。ナレーションとビジュアル JSON はポップアップで編集でき、絵コンテの変更は取り消せます。
- 自動、縦並び、横並び、コンパクトのレイアウトを選べます。複数シーンを選択して長さやスタイルを一括変更でき、情報量の多い内容や縦長レイアウトの問題箇所には移動可能な警告が表示されます。

### ナレーション、テンポ、字幕

- プロジェクトごとに音声プロフィールを作成し、音声サンプルと文字起こしを登録できます。ローカルの F5-TTS で音声に合わせたナレーションを生成します。専用音声がない場合は汎用音声を使用できます。
- プロジェクト全体のナレーションは最大 3 シーンずつ順番に生成し、現在のバッチ、完了数、全体の進捗、処理中のシーンを表示します。
- プロジェクト全体またはシーンごとに速度、文間ポーズ、シーン間隔を調整できます。変更の影響を受けるシーンだけを再生成でき、シーン全体や文・クリップを試聴できます。
- ローカルのアライメントモデルで単語単位の字幕タイミングを作成します。シンプル、背景付き、強調のスタイルを選び、表示、位置、サイズ、色、透明度を設定できます。SRT、VTT、ASS に書き出せます。アライメント情報がない場合はシーンの長さから時間を推定します。
- シーン、プロジェクト、全体の中国語発音補正ルールを設定できます。ルールを変更すると、影響するシーンの音声は再生成が必要な状態になります。

### 画像とプロジェクト素材

- プロジェクト素材ライブラリで画像、音声サンプル、BGM をプレビュー・置換・削除し、出典、ライセンス、クレジットを確認できます。画像シーンでは全体表示またはトリミング表示、拡大縮小、水平・垂直の焦点を設定できます。
- ローカル画像を取り込むか、必要に応じて Wikimedia Commons を検索できます。Commons の画像を使う前にライセンスとクレジットを確認できます。出典情報はプロジェクトに保存され、動画内に表示することもできます。

### プレビュー、レンダリング、書き出し

- Remotion でプレビューし、16:9（1920×1080）または 9:16（1080×1920）、30 FPS の H.264 MP4 を書き出せます。確認用に 540p のドラフト書き出しも利用できます。
- ローカル BGM を追加し、音量、フェードイン、フェードアウトを調整できます。レンダリング履歴には待機、素材準備、映像レンダリング、エンコードの進捗と失敗理由が表示され、実行中のタスクはキャンセルできます。
- 書き出しごとに別の動画ファイルを保存し、プロジェクト履歴からダウンロードできます。旧 V1.0 の共有 `final.mp4` が上書きされてファイルがなくなった場合、復元はできません。その記録は利用不可と表示され、誤解を招くダウンロード操作は表示されません。

### プロジェクト管理、バックアップ、環境診断

- プロジェクト、絵コンテ、素材、音声、タスク、書き出し履歴はローカル SQLite とプロジェクトフォルダーに保存されます。絵コンテは自動保存され、保存状態、エラー、バージョン競合が表示されます。生成や書き出しの前にも保存します。
- プロジェクトの複製、完全な `.m2v` プロジェクトパッケージの作成・ダウンロード、スナップショット作成、重要なスナップショットのロック、スナップショットまたはパッケージから新規プロジェクトとして復元ができます。自動スナップショットは各プロジェクト 5 分に 1 回までで、ロックされていない最新 10 件を保持します。
- プロジェクトパッケージには元ファイル、プロジェクト素材、音声サンプル、シーン音声、存在している独立した過去の動画が含まれます。モデルの重みは含まれません。上書き後に存在しない旧動画は復元できません。
- ホーム画面の環境チェックで Python、Ollama と必要なモデル、FFmpeg/ffprobe、F5-TTS の依存関係、OCR、レンダリング Worker を診断できます。修正の案内は表示しますが、モデルやシステム依存関係を自動インストールすることはありません。
- 長文生成とレンダリングの状態、進捗、エラー、チェックポイントは保持されます。対象タスクはプロジェクト一覧またはプロジェクト画面から再開・再試行できます。

## 基本的な使い方

1. プロジェクトを作成し、資料を取り込むかテキストを貼り付けます。抽出内容を確認し、画角、ビジュアルスタイル、PPTX の処理方法を選びます。
2. 絵コンテを編集し、シーン内容、レイアウト、順序、長さを調整します。必要に応じてテンプレート、一括編集、ローカル画像、Commons 画像を使います。
3. 音声サンプルと文字起こしを設定してナレーションを生成・試聴し、速度、ポーズ、シーン間隔、字幕、発音ルールを確認します。
4. ライブプレビューで映像とレイアウトを確認します。必要ならローカル BGM を追加するか、540p のドラフトを書き出します。
5. MP4 を書き出し、進捗を確認またはキャンセルします。完成した動画は書き出し履歴からダウンロードできます。
6. 納品前に字幕・音声チェックと MP4 検証を行い、納品 ZIP を作成します。よく使う画角、字幕、イントロ、アウトロは書き出しプリセットに保存できます。

## システム要件

以下はローカル開発・動画生成の推奨値であり、アプリの必須チェックではありません。CPU 推論も可能ですが、音声生成は遅くなります。

| 項目 | 推奨最低値 |
| --- | --- |
| OS | 64 bit Windows 10 22H2 または Windows 11 |
| CPU | 現代的な 4 コア。コア数が多いほど生成に有利です |
| メモリ | 16 GB。Ollama と F5-TTS を同時に使う場合は 32 GB 推奨 |
| ディスク | 依存関係、モデル、キャッシュに 25 GB 以上。動画用の追加容量も必要です |
| GPU | 任意。Intel Arc/XPU は F5-TTS を高速化できます。8 GB 以上の VRAM/共有メモリを推奨。XPU が使えない場合は CPU に切り替わります |
| 動画エンコード | Intel Quick Sync は任意。ハードウェアエンコーダーがない場合は FFmpeg の libx264 を使用します |

Python の依存関係は PyTorch XPU 版に固定され、音声高速化は Intel XPU 向けです。NVIDIA/AMD GPU はこの XPU 経路では使われず、音声処理は CPU で行われます。Ollama の GPU 対応は Ollama とドライバーに依存します。

## 必要なソフトウェアとモデル

| ソフトウェア | バージョン / 用途 |
| --- | --- |
| Git と Git LFS | リポジトリの取得とモデル重みの取得 |
| Node.js | 20.19 以上。Next.js と Remotion Worker 用 |
| Corepack と pnpm | リポジトリでは pnpm 11.25.0 を固定使用 |
| Python | 3.13.x。文書解析と音声サービス用 |
| uv | Python 環境の作成とロック済み依存関係のインストール |
| Ollama for Windows | ローカル LLM サービス。既定 API は `http://localhost:11434` |
| FFmpeg | 8.x full-shared。`ffmpeg.exe`、`ffprobe.exe`、共有 DLL が必要 |
| Chrome/Chromium | Remotion はローカルの Chrome を優先し、なければ描画用ブラウザーをダウンロード |
| PowerPoint または LibreOffice | 任意。PPTX の元スライド画像を保持する場合のみ必要 |

Python サービスと Worker の両方から FFmpeg を `PATH` で参照できる必要があります。TorchCodec の固定バージョンには FFmpeg 8 full-shared を推奨し、FFmpeg 9 は推奨しません。スキャン PDF の OCR には Tesseract と言語データを任意でインストールしてください。

| 用途 | モデル |
| --- | --- |
| 資料分析、台本、絵コンテ | Ollama `qwen3:4b` |
| 音声クローン | [SWivid/F5-TTS](https://huggingface.co/SWivid/F5-TTS) |
| F5-TTS ボコーダー | [charactr/vocos-mel-24khz](https://huggingface.co/charactr/vocos-mel-24khz) |

F5-TTS の重みは約 1.35 GB、Vocos は約 55 MB です。F5-TTS モデルは CC BY-NC 4.0 と記載されています。利用前にモデルカードとライセンスを確認してください。モデル重みは Git LFS 経由で取得し、`.m2v` プロジェクトバックアップには含まれません。

## Windows でのセットアップ

### 1. リポジトリと JavaScript 依存関係

```powershell
git clone https://github.com/MiaoShuYo/zhiying.git
cd zhiying
git lfs install
git lfs pull
corepack enable
corepack prepare pnpm@11.25.0 --activate
Copy-Item apps\web\.env.example apps\web\.env
pnpm install
pnpm db:generate
pnpm db:push
```

事前に Node.js 20.19 以上、Git、Git LFS をインストールしてください。pnpm は Corepack 経由で使用し、依存関係のインストールに `npm install` を使わないでください。

### 2. Ollama と LLM

Ollama for Windows をインストールして起動し、次を実行します。

```powershell
ollama pull qwen3:4b
ollama list
```

既定では Ollama は `http://localhost:11434` を使用します。必要に応じて `apps/web/.env` の `OLLAMA_MODEL` または `OLLAMA_BASE_URL` を変更してください。

### 3. Python 音声サービス

Python 3.13.x と [uv](https://docs.astral.sh/uv/) をインストールし、リポジトリのルートから実行します。

```powershell
cd services\python
uv sync --python 3.13 --extra tts
```

`tts` extra は固定バージョンの F5-TTS、PyTorch XPU、TorchAudio、TorchCodec を追加します。PDF 解析だけ必要な場合は `--extra tts` を省略できます。単語単位の字幕アライメントモデルは初回利用時に Hugging Face からダウンロードされます。PPTX の元スライド保持には PowerPoint または LibreOffice が必要です。

### 4. アプリの起動

リポジトリのルートに戻り、次を実行します。

```powershell
cd ..\..
.\start.ps1
```

Python サービス、Next.js、レンダリング Worker が起動し、ログは `logs` に保存されます。[http://127.0.0.1:3000](http://127.0.0.1:3000) を開いてください。スクリプトは Ollama を起動しないため、絵コンテ生成時は Ollama を起動しておきます。停止するには `.stop.ps1` を実行します。

Web と Worker のみ起動する場合は、ルートで `pnpm dev` を実行します。Python サービスだけを起動するには `services\python` で次を実行します。

```powershell
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload --reload-dir app
```

[http://localhost:8000/health](http://localhost:8000/health) でサービス状態を確認できます。プロジェクトのメディアとモデルの保存先を変えるには `M2V_DATA_DIR`、Hugging Face キャッシュには `HF_HOME`、Ollama モデルには `OLLAMA_MODELS` を設定します。環境変数の変更後は関連するターミナルやサービスを再起動してください。

PowerShell がスクリプトをブロックする場合は、`pwsh -ExecutionPolicy Bypass -File .\start.ps1` を使います。

## データと制限事項

- SQLite データベースとメディアはローカルに保存されます。バックアップには素材や過去の書き出しが含まれるため、大容量になる場合があります。
- `.m2v` パッケージにモデル重みは含まれません。存在しなくなった旧 `final.mp4` は復元できません。
- CPU による音声生成は可能ですが低速です。Intel XPU 高速化は Intel 環境向けです。
- 公開ウェブページ抽出ではログインが必要な内容を取得しません。失敗した場合はテキスト貼り付けを利用してください。
- Commons 画像を使う際はライセンスとクレジットを確認してください。モデルと素材のライセンスも適用されます。

詳しいバージョン履歴と実装記録は[中国語 README](README.md)を参照してください。V1.5 の確認シナリオは[手動確認チェックリスト](doc/V1.5_manual_acceptance.md)にあります。
