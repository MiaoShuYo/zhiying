PDF、PPTX、Markdown、公开文章链接或直接粘贴文本；扫描页可用本地 OCR 识别。

WORKFLOW

六步，从一份资料到一条成片

每一步都有可编辑、可检查的中间结果，不用把整条视频交给黑盒。

1

新建项目

导入资料并检查抽取结果；选择画幅、视觉风格、品牌套件与 PPTX 处理方式。

2

生成故事板

本地模型把正文整理成章节与场景，可逐场调整内容、版式、顺序和时长。

3

生成旁白

用参考音频克隆音色，设置语速与停顿，逐词字幕自动对齐，可按需纠正读音。

4

品牌与预览

套用品牌套件的颜色、字体和 Logo，在实时预览里检查画面与排版。

5

导出视频

先导出 540p 草稿审片，满意后输出 1080p、30 FPS 的 H.264 MP4。

6

质检交付

字幕与语音质检、成片文件校验，最后生成包含视频与字幕的交付包。

  • 2
    Node.js 与 pnpm 11用于 Web / Worker / 渲染流程
  • 3
    Python 3 与 FFmpeg语音合成、OCR 与视频编码
  • 4
    Ollama + qwen3:4b本地分镜与读音推理；不需要云端 API Key

完整环境变量、模型与排障说明见 README。

# 1. 克隆仓库
git clone https://github.com/MiaoShuYo/zhiying.git
cd zhiying

# 2. 安装依赖并初始化数据库
pnpm install
pnpm db:push

# 3. 启动（Python + Web + Worker）
.\start.ps1

# PowerShell 拦截未签名脚本时：
powershell -ExecutionPolicy Bypass -File .\start.ps1

启动后访问 http://127.0.0.1:3000。停止服务用 .\stop.ps1（同样可加 -ExecutionPolicy Bypass）。

FAQ

常见问题

我的资料会被上传到云端吗？

不会。资料抽取、分镜、语音、渲染与导出都在本机完成；除你主动发起的网页抓取和 Wikimedia Commons 搜索外，不访问云端服务。

必须要有独立显卡吗？

不必须。CPU 可以完成推理与语音生成，只是会更慢；有 Intel XPU 时语音合成会更快。Ollama 能否使用 GPU 由 Ollama 与驱动决定。

运行 start.ps1 提示“未对文件进行数字签名”怎么办？

这是 Windows PowerShell 的执行策略在拦截未签名的本地脚本，不是项目错误。当前会话临时放行后运行：Set-ExecutionPolicy -Scope Process Bypass -Force；或直接用 powershell -ExecutionPolicy Bypass -File .\start.ps1。也可以读一遍脚本内容，确认可信后再运行。

可以商用吗？

项目使用 MIT License，可自由使用、修改和分发；模型与素材的许可证仍各自适用，请在商用前确认。

能用自己的品牌颜色和 Logo 吗？

可以。V1.6.7 提供品牌套件：在设置页创建品牌（颜色、字体、Logo），新建项目或在项目编辑器里应用。项目保存独立快照，所以之后修改品牌库不会影响已有项目。

旧项目还能打开吗？

能。没有品牌字段的旧故事板继续按原样渲染；历史项目包也可以恢复为新项目。项目数据保留在本地 SQLite 与项目目录中。
