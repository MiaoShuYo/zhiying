# 知影 Zhiying V1.8.0 安装指南

本文适用于知影 Zhiying **V1.8.0** Windows 安装包。模型文件按需下载，安装程序本身不包含完整模型集合。

## 系统要求

- Windows x64（Windows 10/11 64 位）。安装器以当前用户模式运行，默认安装到 `%LOCALAPPDATA%\Programs\Zhiying`，通常不需要管理员权限。
- 为程序、临时安装文件和用户数据保留可写磁盘空间。模型大小依赖所选模型；模型管理器会显示每个模型的下载大小，F5-TTS 与语音对齐模型均约 1.3 GB。
- 本地推理可以使用 CPU；支持的设备和驱动会影响速度。安装和首轮模型下载需要网络；模型文件准备好后，文档导入、项目编辑与渲染可在离线环境运行。

## 安装

1. 从 V1.8.0 发布页获取 `Zhiying-Setup.exe` 及其 SHA-256 校验文件。
2. 双击安装包，按向导选择目录。默认目录为 `%LOCALAPPDATA%\Programs\Zhiying`；不要选择 Windows、Program Files 或磁盘根目录。
3. 在完成页选择立即打开模型管理器下载模型，或稍后再下载。模型下载会写入安装目录下的 `models`。
4. 安装后从桌面快捷方式或开始菜单启动知影。安装日志保存在安装目录的 `logs` 中。

## 模型与许可

V1.8.0 默认清单中的模型及来源以 `apps/desktop/src/model-manifest.default.json` 为准：

| 模型 | 用途 | 清单许可 |
| --- | --- | --- |
| Qwen3 4B | 本地文本生成 | Apache-2.0 |
| F5-TTS v1 Base | 语音合成 | CC BY-NC 4.0，商业使用受限 |
| Vocos Mel 24kHz | TTS 声码器 | MIT |
| Wav2Vec2 XLSR-53 中文 | 字幕对齐 | Apache-2.0 |

下载模型前请阅读对应模型卡和许可证。F5-TTS 权重按上游清单标注为非商业许可；知影不授予第三方模型的额外使用权。模型目录中的文件会按清单校验完整性。

## 离线使用

首次下载模型需要网络。需要离线使用时，请先在模型管理器中下载所需模型并确认状态为已安装；随后关闭网络即可编辑项目和导出本地文件。模型不齐全时，相应的生成能力可能不可用，应用不会自动从互联网抓取视觉素材或音效。

## 修复与升级

重新运行 V1.8.0 安装程序并选择同一安装目录，可执行修复或覆盖升级。安装器会替换程序文件并保留 `models`、`data`、`logs` 和 `config` 中的用户内容。升级前仍建议备份重要项目。

若模型文件缺失或校验失败，可在模型管理器中重新下载；若服务未启动，可先关闭知影后重新启动，并查看安装目录 `logs` 的错误信息。不要手动删除正在使用的安装目录。

## 卸载

可从 Windows“设置 → 应用”或开始菜单中的卸载入口卸载。默认卸载会移除程序文件并保留模型、项目数据、日志和配置；只有明确选择清理用户数据时才删除这些目录。需要保留项目时，卸载前请先导出或备份项目。

## SHA-256 校验

发布包提供 `.sha256` 校验文件。下载后在 PowerShell 中运行：

```powershell
Get-FileHash .\Zhiying-Setup.exe -Algorithm SHA256
```

将输出的 64 位十六进制值与 V1.8.0 发布页提供的 SHA-256 值比较；不一致时不要运行该安装包，请重新下载。
