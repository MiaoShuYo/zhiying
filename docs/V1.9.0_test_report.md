### v21 失败诊断

状态更新：以下首轮失败为历史诊断记录。根代理最终复跑 `pnpm test:v21` exit 0（133 pass、0 fail、19 skip）；R4 Inno/frozen dist 项因产物未构建而 skip。随后 `pnpm test:v21:e2e` exit 0（14 tests，13 pass、0 fail、1 skip），实际构建两份 release 目录和 Inno 包并通过安装/升级/卸载/启动/下载恢复；只有缺少 dist 基线导致的“不改变 dist”检查跳过。

- `apps/desktop/test/103-installer.test.ts:306`：测试未读到 HKCU `...\Uninstall\Zhiying` 项。`pnpm test:v21` 的输出仅给出断言“HKCU 卸载注册表项不存在”，没有打印 `executeInstall().warnings`。随后用隔离临时安装目录做单次诊断：`pnpm exec tsx data/v21-reg-diagnostic.ts` 返回 `ok:true`、`warnings:[]`、`errors:[]`，读回 DisplayName、DisplayVersion、InstallLocation、UninstallString 等值；清理后 registry key 不存在。诊断脚本已删除。Installer 与其测试文件没有被本次修改。这个结果排除持续的 HKCU 权限限制；该 test suite 的其他用例也操作同一个全局卸载 key，因此首次失败更像并行用例的清理/写入竞态，尚未通过完整 v21 串行复跑确认。
- `apps/desktop/test/106-maintenance.test.ts:514`：仓库缺少测试要求的 `doc/V1.8.0_install.md`。该路径在工作树和 `docs/` 下均不存在，installer/doc 文件未被本次修改；因此这是既有桌面安装文档缺项，与 V1.9.0 视觉变更无关。

上两条描述的是首轮诊断时的状态。之后根代理补齐了安装指南，并复跑 `pnpm test:v21` 与桌面 E2E；最终结果分别为 133 pass/0 fail/19 skip，以及 13 pass/0 fail/1 skip。
